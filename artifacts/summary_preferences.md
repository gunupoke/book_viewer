# ユーザーの要約における嗜好・トーンの学習記録

ユーザーが直接修正したデータ（`yorozuya ver3.5 - books_v2_final_k.csv` 内の69件の修正）を分析し、以下の傾向を抽出して記憶しました。今後のGemini要約生成において、以下のルールを厳格に適用します。

## 1. 客観性と簡潔さの徹底
- **主観的な評価・絶賛の削除**: 「傑作」「必読」「おすすめ」「指南本」などのような、AIによる主観的・セールス的な評価表現は好まれません。作品のあらすじ・事実・テーマのみを簡潔に記載すること。
- **キャッチコピー的な修飾語の排除**: 「〜とキャッチーな言葉で誤魔化すための」などの煽り文句や、余分な修飾語はカットする。

## 2. 物理的付録・特典情報の削除
- **付録情報**: 「特大ポスターとシール付き」のような、書籍の内容そのものではない物理的な付録や特典についての情報は不要。

## 3. エッセイ・哲学書の知的要約
- **テーマの掘り下げ**: エッセイや思想・哲学を扱う本については、表面的な説明ではなく「人間とは何か」「ポストモダンの視点から」のように、本質的なテーマや切り口を抽出して知的なトーンでまとめること。

## 4. 総括
- あらすじは「どんな物語か」「どんなテーマか」だけをストレートに伝える。
- 販促文句のような余計な装飾を削ぎ落とし、クールで事実ベースの文体を維持する。
